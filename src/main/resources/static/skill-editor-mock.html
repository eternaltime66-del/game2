这是个技能开发模拟页

充能条件

角色类：首位选角色，每触发 x 次增加 y 充能（「主动技能效果」≠ 完整主动技能）。行动值类：全局，每增加 x 点行动值增加 y 点充能。

主动技能效果

效果列表；每个效果是一个模拟公式编辑器（最多 7 项）。点选读取 / 数字 / 运算符拼公式。

技能选择

仅技能生命周期锚点可用：指定某个 / 指定类型 / 全部（普攻也视为技能）。

被动效果

切入锚点后触发的效果（暂复用主动公式编辑器结构）。

全局读取项

四级联动 · 所有锚点可用 · 公式参数同源
